Dit is het eindwerk van 607IICT1 gemaakt door Sander Maes.

- Startup folder: In de startup folder bevindt zich een python file genaamd Startup.py, de bedoeling hiervoor is om gemakkelijk de server en de API te kunnen opstarten. Requirements.txt bevindt zich hier ook in.

- Server folder: Dit is waar het meest van de code bevindt aangezien de Server alles moet doen van API requests of sturen, de modular systeem van de website afhankelijk welk soort het is apparaat of PLC.

- PLC folder: In deze folder staat de PLC code zodat de server met een PLC kan communiceren, een PLC zoeken op het netwerk of dat rechtstreeks verbonden is aan de server.

- Logging Centrum folder: In deze folder zit de logging service met Docker bestanden, hierdoor wordt alles gelogd wat er met de API aan het gebeuren is.

- Database folder: In deze folder staan de database bestanden en het schema, hierin zal alles opgeslagen worden, accounts, apparaten(devices), user settings/permissions,  etc.
