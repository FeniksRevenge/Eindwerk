# Server Dashboard

Modulair dashboard met snap-to-grid, multi-user layout in SQLite.

## Installatie
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Starten
```powershell
python app.py
```

Ga naar `http://localhost:7000`.
